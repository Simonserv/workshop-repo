# Workshop Guides

A three-session workshop where you build a three-tier catalog and membership website. Each student owns their own GitHub repo, Supabase project, and Vercel site.

## Read in this order

1. **[Prerequisites](./Prerequisites.md)**: do this before Session 1 (accounts and installs).
2. **[Session 1: Build the Storefront](./Session-1-Setup-Reference.md)**: fork, run, deploy, and customize the catalog.
3. **[Session 2: Provision Your Backend](./Session-2-Setup-Reference.md)**: create your Supabase project, run the SQL, and connect your keys.
4. **[Session 3: Operate the Business](./Session-3-Setup-Reference.md)**: seed roles, run the dashboards, and go live.

**Facilitators:** see the **[Facilitator Timing Guide](./Facilitator-Timing-Guide.md)** for the per-session run-of-show (12:30 to 4:00 with break slots).

## At a glance

| Session | You'll do | You'll end with |
|---------|-----------|-----------------|
| Prereqs | Create GitHub/Supabase/Vercel accounts, install Node/VS Code/Git, prep a GCash QR | A ready-to-go laptop |
| 1 | Fork, run, deploy, and customize listings and branding | A live, personalized catalog |
| 2 | Create your Supabase backend, run SQL, paste your keys | Inquiries, receipts, and donations that persist |
| 3 | Seed roles, operate dashboards, final deploy | A working site you fully own |

> Everything stays on free tiers. There is no shared backend, so your project is entirely your own.
